# 🌴 Green Gabes - Système Intelligent de Recommandation Agricole

## 📋 Description

Green Gabes est une **application web intelligente** qui génère des **rapports agricoles personnalisés** basés sur l'IA pour les agriculteurs du gouvernorat de Gabès (Tunisie). L'application analyse les caractéristiques du terrain (sol, eau, superficie, objectif) et fournit des recommandations détaillées et professionnelles via un formulaire bilingue (Français/Arabe).

### 🎯 Fonctionnalités principales

- ✅ **Formulaire interactif bilingue** (Français/Arabe) avec 2 pages et champs dynamiques
- ✅ **Analyse IA intelligente** (Groq - Llama 3.3-70B) avec optimisation tokens
- ✅ **Cache intelligent** (mémoire + disque 24h) pour performances optimales
- ✅ **Compression contexte** (règles techniques + réglementation + stats) sans perte de qualité
- ✅ **Génération PDF professionnel** (design Green Gabes avec branding)
- ✅ **Téléchargement direct** du rapport (sans accès au code/dossiers)
- ✅ **6 sections obligatoires** : Diagnostic, Plantation, Hydrique, Alertes, Budget, Calendrier
- ✅ **Données locales complètes** : Code des Eaux, PDL 2035, APIA, CRDA, zones Gabès
- ✅ **Budget phasé** avec subventions APIA détaillées
- ✅ **Calendrier mensuel** année 1 (janvier-décembre)
- ✅ **Rendements projetés** années 1, 3, 5
- ✅ **Alertes maladies** (Fusariose, Oïdium, Araignée rouge) avec coûts traitement
